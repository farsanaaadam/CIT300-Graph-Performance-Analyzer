# Data Structure and Graph Performance Analyzer

## Project Description
A Java console-based application for CIT300 Data Structures and Algorithms (Graded Practical Assignment 2). It demonstrates Arrays, Stacks, Queues, Linked Lists, Searching (Linear and Binary), Graphs (BFS and DFS), and a performance comparison of algorithms using step counts and execution time.

- Array, Stack, Queue and Linked List operations
- Linear Search and Binary Search with step comparison
- Graph with BFS and DFS traversal
- Performance comparison (steps and execution time)
- Display of all results
- Input validation and empty-structure handling

## How to Run
1. Install JDK 17 or later.
2. Clone the repository:
   `git clone https://github.com/farsanaaadam/CIT300-Graph-Performance-Analyzer.git`
3. Go to the source folder:
   `cd CIT300-Graph-Performance-Analyzer/src`
4. Compile:
   `javac *.java`
5. Run:
   `java Main`
